# HALDEN — homepage

Static site (HTML/CSS/vanilla JS), no build step. Deployed on Vercel from `main`.

- `index.html`, `styles.css`, `main.js` — the page
- `img/` — generated AVIF/WebP variants (commit them)
- `source-images/` — originals, kept locally only (git-ignored); regenerate variants with `npm install && npm run images`
- `fonts/` — self-hosted latin subsets of Hanken Grotesk and Playfair Display (SIL OFL)
